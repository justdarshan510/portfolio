## ✨ Highlights & Key Features

- **📱 Fully Responsive Design**: Seamless layout transition mapping between desktop and mobile screen sizes.
- **🕹️ Interactive 3D Canvas Elements**: 3D computer setup elements placed dynamically in background corners that respond with float animations and ambient shadows on mouse hover/drag.
- **🧲 Responsive Magnet Hover Effect**: Real-time cursor-following and touch-drag movement animations applied to the main profile avatar.
- **⚙️ Apple UI Style Symbols**: Custom navigation links utilizing precise system-ui style symbols (`User`, `Wrench`, `Folder`, `Mail`).
- **📦 Portal-Based Iframe Sandbox**: Fully integrated sandbox browser mockup overlay using React Portals to preview live projects without redirects or z-index context conflicts.
- **✨ Fluid Animations**: Smooth page entries, tab transitions, and exit wipes powered by Framer Motion.

## 📂 Featured Project

### **🏏 CricBid (IPL Player Auction Simulator)**
A real-time multiplayer cricket bidding and player auction application built to simulate professional league drafts.
- **Overview**: Users join live lobby rooms, manage franchise budgets, bid dynamically on players, and inspect player performance metrics to assemble a championship team.
- **Key Technical Highlights**:
  - **Real-Time Synchronization**: Managed active bidding rooms using Firestore Realtime Listeners/WebSockets.
  - **Transactional Consistency**: Implemented strict client/server budget check validations to prevent overdrafts.
  - **Optimized UI Performance**: Designed an optimistic state update mechanism to keep bid updates under 100ms.
- **Tags**: `Real-time Bidding` · `Lobby Rooms` · `Budget Tracking` · `Draft Analytics`

## 🚀 Getting Started Locally

To get a local copy of this portfolio running, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/justdarshan510/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build the production bundle:**
   ```bash
   npm run build
   ```
